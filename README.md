## WHAT IS KINETIC WALLET?

Kinetic is a fully open-source, non-custodial multichain wallet engineered for instant cross-chain settlement. Your keys never leave your device. Your assets move across 16+ networks in under 2 seconds — without friction, without compromise.

**Smart contracts deployed on:**
- Sepolia Testnet
- Base Sepolia
- Polygon Amoy

| Feature | Description |
|---|---|
| ⚡ Sub-2s Settlement | Near-instant cross-chain transaction finality |

## QUICK START

```bash
# Clone the repository
git clone https://github.com/kineticwalletdotfun/koneticwallet.git
cd koneticwallet

# Install dependencies
npm install

# Run tests
npm test

# Deploy to testnet
npm run deploy:testnet
```
